# SystemManager

Este proyecto fue hecho con la idea de familiarizarme con algunos conceptos de Electron y webdev

System Manager es una aplicación que lee el uso de la CPU (en %), la RAM y el espacio del disco duro.
Grafica estos 3 parámetros en un gráfico, como el task manager de Windows.
Por ahora sus funcionalidades son limitadas, y quizá lo expanda en un futuro
